## Robotics Lab

Beyond Media ведёт на точный домен проекта. На GitHub профиль `0xCodez` указывает Beyond Media и аккаунт `@0xMovez`. [Каталог Beyond Media](https://beyond-media.ai/projects) · [GitHub автора](https://github.com/0xCodez) · [Публикация автора](https://x.com/0xMovez/status/2120239217880268919)

Деплой отдаёт читаемый `js/app.js`, который загружает `js/lab/lab.js`. В модуле лаборатории есть подключение проводов, объединение выводов в электрические сети и распространение уровней сигналов. В режиме свободной сборки компоненты реагируют на уровни HIGH/LOW, мигание и PWM. LED, кнопки, потенциометры, датчики и приводы имеют собственное поведение. Примеры скетчей отображаются для чтения. При запуске миссии вызывается её готовый JavaScript-сценарий, который обновляет компоненты и пишет строки в Serial. Вычисление токов и исполнение редактируемых скетчей в проверенном модуле не обнаружены. [Сайт](https://robotics-lab-app.vercel.app/) · [Точка входа](https://robotics-lab-app.vercel.app/js/app.js) · [Модуль лаборатории](https://robotics-lab-app.vercel.app/js/lab/lab.js)

## Упражнения Arduino Uno в RoboEasy

Вкладка `/[lang]/learn` открывает существующую лабораторию с примерами миссий `led`, `button`, `dimmer` и `radar`. Источник схем и скетчей — `lib/electronics/missions.ts`. При первом открытии с `setup=example` загружаются проводка и скетч примера. Правки из «Уроков» сохраняются отдельно от рабочего черновика миссии. Для ESP32 вкладка показывает доступность платы.

Браузерная проверка `tests/e2e/electronics.spec.ts` открывает каждое упражнение из «Уроков» и сверяет провода и код. В Serial сценарий запускает дальномер, редактирует `Serial.print`, затем убирает провод ECHO. Монитор порта отражает изменения скетча и подключения. Этот сценарий проверяет существующий симулятор RoboEasy.
